# Using Superpowers

## Purpose
Understand the Superpowers skill system and how its mandatory workflows trigger.

## When to use
At the start of a session or when the agent seems to be skipping required skills.

## Core steps
1. Recognize that skills trigger automatically based on the conversation context.
2. The core loop is: brainstorming → (using-git-worktrees) → writing-plans → subagent-driven-development / executing-plans → test-driven-development → requesting/receiving code review → finishing-a-development-branch.
3. If something misbehaves, invoke diagnosing-superpowers with the session ID.
4. Don't bypass the workflow; the skills are mandatory, not suggestions.
