# Brainstorming

## Purpose
Turn an initial request into a shared, testable understanding before implementation.

## When to use
Before designing or building a feature, especially when scope or expected behavior is ambiguous.

## Core steps
1. Ask one focused question at a time about users, outcomes, constraints, and edge cases.
2. Inspect relevant repository conventions and summarize the intended behavior in small chunks.
3. Offer a small set of viable approaches with trade-offs; recommend the simplest that meets the need.
4. Confirm the design with the user before implementation. Keep small changes agreed in chat; capture larger designs in a repository-appropriate document.
