# Wizard

## Purpose
Help users complete a multi-step task through a clear, sequential interaction.

## When to use
When several choices or inputs are needed and order matters.

## Core steps
1. Explain the goal and the steps ahead.
2. Ask for one piece of information at a time, retaining context.
3. Validate each response before moving forward.
4. Summarize the completed choices and obtain confirmation before consequential actions.
