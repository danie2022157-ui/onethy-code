# To Tickets

## Purpose
Convert a plan or spec into discrete tickets with owners and acceptance criteria.

## When to use
When work spans multiple people or needs tracking beyond a single session.

## Core steps
1. Break the plan into small, self-contained tickets.
2. Assign each ticket clear acceptance criteria and required files.
3. Note dependencies and ordering between tickets.
4. Record them in the project's issue tracker if available.
