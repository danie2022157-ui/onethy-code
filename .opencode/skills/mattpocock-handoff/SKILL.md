# Handoff

## Purpose
Transfer context so work can continue across sessions or agents.

## When to use
When delegating, switching sessions, or pausing long-running work.

## Core steps
1. Summarize the goal, current state, and completed steps.
2. List open tasks with file paths and next actions.
3. Record key decisions, constraints, and gotchas.
4. Point to verification steps so the next agent can confirm state.
