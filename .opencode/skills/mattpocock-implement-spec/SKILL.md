# Implement Spec

## Purpose
Deliver a confirmed spec while preserving scope and making verification explicit.

## When to use
When an approved specification already exists.

## Core steps
1. Map each acceptance criterion to a code change and test.
2. Follow test-first development and existing module boundaries.
3. Implement only the agreed scope; surface contradictions instead of guessing.
4. Run acceptance tests plus relevant package checks.
5. Report criteria met and any limitations.
