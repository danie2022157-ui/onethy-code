# Grill Me

## Purpose
Challenge an idea with questions so the user arrives at a sharper, testable plan.

## When to use
When a user has a rough idea that needs pressure-testing before work begins.

## Core steps
1. Restate the idea in your own words and ask the user to confirm.
2. Probe the underlying goal, assumptions, and success criteria.
3. Surface risks, edge cases, and simpler alternatives.
4. Converge on a crisp, shared statement of what to build.
