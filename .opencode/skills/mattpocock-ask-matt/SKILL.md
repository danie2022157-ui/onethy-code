# Ask Matt

## Purpose
Get a second opinion when an engineering choice is unclear.

## When to use
When facing a non-trivial architecture, design, or implementation decision and a specialist subagent is available.

## Core steps
1. Frame the question with repository context, constraints, and candidate options.
2. Ask a relevant specialist subagent for a focused opinion when useful.
3. Compare the recommendation against project conventions and actual requirements.
4. Tell the user the reasoning and uncertainty; do not claim external consultation unless performed.
