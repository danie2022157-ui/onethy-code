# Triage

## Purpose
Decide what to investigate first based on user impact and urgency.

## When to use
When multiple bugs, tasks, or reports compete for attention.

## Core steps
1. Establish user impact, reproducibility, urgency, and affected scope.
2. Separate confirmed facts from assumptions.
3. Rank items by impact and risk, not by ease or recency.
4. Communicate priority and rationale; ask the user when priorities conflict.
