# Retro

## Purpose
Learn from completed work and identify practical improvements for next time.

## When to use
After a meaningful feature, incident, or multi-step effort.

## Core steps
1. Compare outcomes against expectations and the plan.
2. Identify what went well, what caused friction, and why.
3. Propose one or two specific, actionable improvements.
4. Record durable project-level learning in the appropriate memory or docs.
