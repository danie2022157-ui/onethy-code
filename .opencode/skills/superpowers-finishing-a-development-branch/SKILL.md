# Finishing a Development Branch

## Purpose
Complete a development branch with verification and a clear merge/discard decision.

## When to use
When all tasks on a branch are complete.

## Core steps
1. Run the full test suite and ensure a clean baseline.
2. Present options to the user: merge, open PR, keep branch, or discard.
3. If merging or PR'ing, prepare a clear summary of changes.
4. Clean up the worktree after the decision is executed.
