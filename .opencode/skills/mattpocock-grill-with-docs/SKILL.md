# Grill With Docs

## Purpose
Eliminate ambiguity before implementation through focused questions and local documentation.

## When to use
When the request has unclear outcomes, terms, constraints, or important edge cases.

## Core steps
1. Inspect relevant documentation and code to learn established terminology.
2. Ask concise questions about intended outcome, scope, and constraints.
3. Reflect back the understanding for confirmation.
4. Record durable decisions in the existing project documentation, avoiding redundant files.
