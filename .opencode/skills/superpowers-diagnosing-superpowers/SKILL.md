# Diagnosing Superpowers

## Purpose
Determine what went wrong in a session that used this skill system and report it with evidence.

## When to use
When skills trigger incorrectly, stay silent, or the agent deviates from its plan.

## Core steps
1. Identify the affected session (current or by session ID).
2. Read the session transcript and locate the relevant decisions.
3. Report what happened with line-level evidence.
4. Optionally package a scrubbed bundle suitable for a bug report.
