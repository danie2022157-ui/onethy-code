# Writing For Agents

## Purpose
Author instructions, prompts, and skills that agents can follow consistently.

## When to use
When creating or editing prompts, skills, or agent-facing documentation.

## Core steps
1. State the goal, context, and success criteria explicitly.
2. Use imperative steps and concrete tool names (subagent, worktree, test, typecheck).
3. Specify when to use the instruction and when not to.
4. Include verification steps and attribution where adapted.
5. Test by running the agent and refining ambiguous phrasing.
