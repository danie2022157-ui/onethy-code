# Implement

## Purpose
Translate approved requirements into minimal production code.

## When to use
Once the user has confirmed the goal and implementation scope.

## Core steps
1. Inspect relevant modules, tests, and repository rules.
2. Write or update tests first for the desired behavior.
3. Implement the smallest change consistent with the spec and existing architecture.
4. Run focused tests and relevant typecheck/lint/build.
5. Review the diff for scope and regressions before reporting completion.
