# Requesting Code Review

## Purpose
Obtain a structured review of changes before finalizing them.

## When to use
Between tasks or before finishing a branch.

## Core steps
1. Summarize what changed and which task/plan it addresses.
2. Provide the diff or affected files to the reviewer.
3. Ask for issues classified by severity (critical, major, minor).
4. Treat critical issues as blocking progress.
5. Route fixes back through verification.
