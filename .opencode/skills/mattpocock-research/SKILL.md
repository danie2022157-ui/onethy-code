# Research

## Purpose
Gather evidence on technical options before making implementation decisions.

## When to use
When there are competing approaches and the best choice is not evident.

## Core steps
1. Formulate the specific uncertainty to resolve.
2. Inspect documentation, code, and repo conventions for clues.
3. Summarize findings with trade-offs and confidence level.
4. Recommend the option that best fits project constraints.
