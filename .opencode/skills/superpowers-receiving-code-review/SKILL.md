# Receiving Code Review

## Purpose
Act on review feedback systematically without introducing regressions.

## When to use
After receiving review comments on your work.

## Core steps
1. Triage feedback by severity and validity; verify claims against the code.
2. Address critical and major issues first.
3. Make minimal, targeted changes per comment; avoid unrelated refactors.
4. Re-run verification after fixes.
5. Note any feedback you disagree with and why, deferring to the user when needed.
