# Teach

## Purpose
Help a user understand a concept, system, or change through clear explanation.

## When to use
When the user wants to learn rather than have code changed.

## Core steps
1. Gauge the user's current level and target understanding.
2. Explain from first principles, building on what they know.
3. Use concrete examples grounded in the actual codebase.
4. Check understanding and offer a quick exercise or recap.
